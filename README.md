## Homework 3
This repository is a homework project for the course Stat 159/259 at UC Berkeley.
The goal is to transform the original LIGO Gravitational Wave Detection tutorial into a small, organized Python package.

# What this homework does
Organizes the original notebook’s data, figures, and audio into separate folders.
Converts the ligotools folder into an installable Python package with pyproject.toml.
Adds a utils.py module with functions moved out of the notebook.
Adds automated tests for readligo.py and utils.py.
Builds a MyST website for the notebook, and deploys it with GitHub Pages.
Includes a Makefile with standard build, clean, and environment commands.
